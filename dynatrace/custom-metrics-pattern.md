# Custom Metrics Pattern

Useful EDM metrics:

- `edm.batch.duration_ms`
- `edm.batch.records_in`
- `edm.batch.records_out`
- `edm.data_quality.exception_count`
- `edm.source_file.missing_count`
- `edm.distribution.failure_count`
- `edm.sql.dependency_latency_ms`

Dimensions:

- environment
- job_name
- source_system
- consumer_name
- rule_code
- severity
