# Interview Demo Script

1. Run a sample job and show structured JSON logs with correlation IDs.
2. Explain how the same correlation ID flows through Python, ADF, SQL, and distribution.
3. Show KQL queries for failed jobs, missing files, DQ spikes, and end-to-end trace.
4. Show SQL monitoring tables for support teams and operational reporting.
5. Show Bicep alert examples and explain action groups.
6. Discuss Azure Monitor and Dynatrace coexistence.

Talking point: modernization is not complete when data moves to Azure. Teams also need operational visibility, runbooks, alerts, and traceability.
