# Incident Response Guide

Severity guidance:

- Sev 1: golden source unavailable or critical downstream distribution missed.
- Sev 2: major batch SLA breach with business impact.
- Sev 3: isolated source delay or recoverable data quality spike.
- Sev 4: warning-level anomaly without current SLA risk.

Every incident should capture impact, start time, detection source, correlation ID, mitigation, root cause, and follow-up action.
