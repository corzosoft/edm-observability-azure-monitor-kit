# SLA and SLO Guide

Example SLOs:

- 99% of file ingestion jobs complete within 30 minutes of expected arrival.
- 95% of reconciliation jobs complete within 45 minutes.
- Critical downstream distribution completes before market-open cutoff.
- Data quality error rate remains below agreed threshold by source system.

Track both customer-facing SLA breaches and internal early-warning SLO burn rates.
